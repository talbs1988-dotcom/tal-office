# המשרד

הקיט של סדנת Claude Code Business של טל בשור. מקים לבעל העסק משרד מסודר עם Claude Code: קלוד מכיר את העסק, זוכר מה שלמד, שומר כל דבר במקום שלו, ובונים יחד סקיל וסוכן ראשונים. בעברית, שלב אחרי שלב.

עובד אותו דבר ב-VS Code, באפליקציה של Claude ובטרמינל, במק ובווינדוס. אין בו קוד שרץ במחשב, ולכן לא צריך להתקין שום דבר נוסף.

## התקנה

**ב-VS Code** (בחלון של Claude Code):

1. מקלידים `/plugins` ← לשונית Marketplaces ← מוסיפים: `talbs1988-dotcom/tal-office`
2. לשונית Plugins ← `tal-office` ← Install ← Install for you

**בטרמינל:**

    claude plugin marketplace add talbs1988-dotcom/tal-office
    claude plugin install tal-office@tal-office

בווינדוס צריך את Git for Windows (https://git-scm.com/download/win) לפני ההוספה.

אחרי ההתקנה פותחים שיחה חדשה.

## מתחילים

1. יוצרים תיקייה ריקה בשם העסק, בתיקיית הבית (שם קצר באנגלית, בלי רווחים).
2. פותחים אותה ב-VS Code (File ← Open Folder), או בוחרים אותה באפליקציה.
3. מקלידים `/office-start`.

ומשם, בכל רגע: `/office`, איפה אנחנו ומה עכשיו.

## השלבים

| שלב              | פקודה              | מה נבנה                                   |
| ---------------- | ------------------ | ----------------------------------------- |
| 1. הקמת המשרד    | `/office-start`    | כל התיקיות, המפה, הזיכרון והאבטחה         |
| 2. להכיר את העסק | `/office-business` | כרטיס העסק ב-CLAUDE.md, ובדיקת זיכרון     |
| 3. מפת העסק      | `/office-map`      | מיפוי המשימות, צוואר הבקבוק, ובחירת משימה |
| 4. סקיל ראשון    | `/office-skill`    | נוהל כתוב, ומתכון שמריץ אותו              |
| 5. סוכן ראשון    | `/office-agent`    | עובד שעושה את המשימה, וריצה אמיתית        |

## המשרד שנבנה

```
<שם-העסק>/
├── CLAUDE.md        תעודת הזהות: העסק, מפת המשרד והכללים. עד 200 שורות. קלוד קורא אותו בכל שיחה
├── memory/          MEMORY.md (תוכן עניינים קצר, נטען בכל שיחה) + קבצי נושא שנקראים לפי הצורך
├── systems/         מפת העסק, ותיקייה לכל מחלקה עם הנהלים שלה
├── projects/        תיקייה לכל פרויקט, ובתוכה מה שקלוד מכין
├── team-ai/         כרטיס לכל עובד דיגיטלי
├── archive/         מה שנסגר
├── .claude/         ההגדרות, המתכונים (skills) וקבצי העובדים (agents)
├── .env             הכספת למפתחות (נוצרת כשמחברים כלי ראשון)
└── .gitignore       שומר שהכספת לא תעלה לאינטרנט
```

`/office-start` בונה את כל התיקיות בבת אחת, ובכל אחת שלט (`README.md`) שאומר מה יש בה.
